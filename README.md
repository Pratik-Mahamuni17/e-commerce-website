# 🛒 E-Commerce Web Application

This is a full-stack **E-Commerce Website** project developed using:
- **Frontend**: Angular
- **Backend**: Spring Boot (Java)
- **Database**: MySQL
- **ORM**: Hibernate

## 📌 Features

### 🧑‍💼 User Module:
- User registration & login 
- Browse product listings
- Product search and filter
- Add to cart and checkout
- Order history

### 🛍️ Admin Module:
- Admin login
- Product CRUD operations (Add, Update, Delete, List)
- View all orders
- Manage users

## 🛠️ Tech Stack

| Layer         | Technology           |
|---------------|----------------------|
| Frontend      | Angular              |
| Backend       | Spring Boot (Java)   |
| ORM           | Hibernate            |
| Database      | MySQL                |
| Security      | Spring Security + JWT |
| Tools         | Postman, Git, GitHub |
